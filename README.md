# Clave

Сайт нейропродакшена Clave в направлении **Black Gold Gallery**: тёмный архивный зал, чёрные рамы с тёплым золотым светом и разные кинематографичные миры внутри. Это первая сборка сайта и активная база для дальнейшей доработки. Картонный лофт и коробочный вариант не использовать.

Тексты и структура: `КОНЦЕПТ.md`. Порядок улучшений: `docs/ПЛАН-РАБОТ-САЙТ.md`. Активный арт-дирекшн: `docs/clave-site-visual-direction-v3.md`. Разработчику: `docs/clave-cursor-developer-handoff.md`. Активные страницы и ассеты — в `site/`; коробочные эскизы в `preview/` и `blender/` — архивные.

Локальная главная: `site/index.html`
