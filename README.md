# Clave

Сайт нейропродакшена Clave в направлении «Картонный архив»: коробка из крафтового картона, нефтяной лофт и кинематографичный пролёт к фильму. Clave готова создавать любые видео для брендов и рекламных агентств.

Тексты и структура: `КОНЦЕПТ.md`. Порядок реализации: `docs/ПЛАН-РАБОТ-САЙТ.md`. Арт-дирекшн: `docs/clave-site-visual-direction-v2.md`. Разработчику: `docs/clave-cursor-developer-handoff.md`. Страницы лежат в `site/`, исходные сцены — в `blender/`, референсы и рендеры — в `preview/`.

Локальная главная: `site/index.html`
